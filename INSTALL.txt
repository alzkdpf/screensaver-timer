Screen Saver Timer 1.6.0 — Apple Silicon

설치: Screen Saver Timer.app을 Applications 바로가기로 드래그하세요.
DMG를 추출한 뒤 응용 프로그램 폴더에서 앱을 실행하세요.

감시 시작 → 유휴 시간이 지나면 38% 검은 레이어 → macOS 화면 보호기 → 디스플레이 끄기.
레이어 표시 시간과 화면 보호기 표시 시간은 각각 설정합니다. 기본값은 각 60초입니다.
입력이 들어오면 레이어를 걷고 다음 단계로 넘어가지 않습니다.
Dock 아이콘과 메뉴 막대에서 남은 시간을 볼 수 있습니다.
