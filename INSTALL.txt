Screen Saver Timer 1.4.1 — Apple Silicon

설치: Screen Saver Timer.app을 Applications 바로가기로 드래그하세요.
DMG를 추출한 뒤 응용 프로그램 폴더에서 앱을 실행하세요.

대기 시간을 설정하고 감시 시작을 누르세요.
마우스나 키보드 입력 시 남은 시간이 설정값으로 돌아갑니다.
창을 최소화해도 Dock 아이콘과 메뉴 막대에서 카운트다운을 볼 수 있습니다.
화면 보호기 시작 신호를 받은 뒤 설정한 시간이 지나면 디스플레이 잠자기를 요청합니다. 기본값은 60초입니다. 화면 보호기가 종료되거나 입력하면 예약을 해제합니다.
