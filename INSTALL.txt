Screen Saver Timer 1.1.0 — Apple Silicon

설치: Screen Saver Timer.app을 Applications 바로가기로 드래그하세요.
DMG를 추출한 뒤 응용 프로그램 폴더에서 앱을 실행하세요.

설정 간격마다 화면 보호기를 반복 실행합니다.
5분 설정 → 반복 시작 → 5분마다 실행 요청.
화면 보호기에서 복귀해도 반복 유지. 취소 또는 앱 종료 시 중단.
잠자기 중 놓친 주기는 한 번만 처리한 뒤 다음 간격을 기다립니다.
지금 실행 버튼은 기존 반복 예약을 유지합니다.

Developer ID 서명·Apple 공증 없음 (로컬 ad-hoc 서명).
다운로드한 앱이 차단되면 출처를 확인하고 실행을 시도한 뒤
시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기에서 승인하세요.

현재 검증 환경: macOS 26.6.2, Apple Silicon.
실제 화면 보호기 전환은 검증하지 않았으며 프로세스 감지는 화면 표시를 보장하지 않습니다.
